# Follow-ups due

Usage: "read prompts/follow-ups.md and do it".

1. Read `AGENTS.md`, `playbook/outreach.md` and `leads.md`.
2. If an email MCP is connected, search the inbox for replies from every Active lead first. A reply changes the next action; never follow up on a thread that already got an answer.
3. List every lead whose next action is due today or overdue.
4. For each: draft the follow-up per the playbook (follow-up 1: 2 lines plus one new thing; follow-up 2: one line; after that, mark the lead closed). Save as a draft in the same thread if connected, otherwise in `outreach/queue/<YYYY-MM-DD>-follow-ups.md`.
5. Update `leads.md` with the new dates.
6. Reply with a table: company | which follow-up | draft ready | new next date.

Never send.
