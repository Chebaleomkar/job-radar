# Research one company

Usage: "read prompts/research-company.md and do it for <company name or URL>".

1. Read `AGENTS.md`, `profile/me.md`, `profile/facts.md`, `playbook/outreach.md`. Check `leads.md` and `companies/` for an existing file; update it rather than starting over.
2. Research, sources first (AGENTS.md 4.1 order): site, careers, docs, blog, founder posts, primary news, GitHub org. Every fact gets a source URL and date; anything unverified is marked.
3. Cover:
   - What they build, for whom, business model, customers (only if public).
   - Funding: rounds, amounts, investors, dates (primary sources; aggregators as unverified hints).
   - Founders and key engineers: background and track record, with profile links.
   - Team size, locations, remote policy, visa signals.
   - Open roles that fit the user (open each live posting) and the interview process if public.
   - Open source: repos where a PR from the user could land, and whether outside PRs get merged.
   - Is it a good place to work: reviews, tenure, red flags. Say plainly when nothing is public.
4. Write the brief to `companies/<name>.md` in the AGENTS.md 4.1 format, with an email draft and a LinkedIn/X note.
5. End with a verdict for the user (apply now / build proof first / skip) and the single best next step.

Never send or apply.
